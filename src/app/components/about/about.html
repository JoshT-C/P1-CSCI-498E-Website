About

I'm a computer science student who likes the parts of a system you can open the case on.

The local stack above is the current obsession: serious models on a single machine, with every layer readable — from the prompt in to the build underneath. When something is slow, I want to be able to find where. When something is wrong, I want to be able to fix it without filing an issue against a company I'll never speak to.

Local-first is a position, not just a preference. If the model, the search, and the document pipeline are all on the box, the interesting questions stop being trust questions and start being engineering questions — quantization, context windows, VRAM reclamation. Those are questions I can actually do something about.

This site is Angular and three.js, self-hosted on my own server behind nginx with Let's Encrypt. If something here is broken, the source is public and the issue tracker is open.
